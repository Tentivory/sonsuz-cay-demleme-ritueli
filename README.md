# Sonsuz Çay Demleme Ritüeli

## Bu Proje Nedir?

Bu, insanlığın en büyük icadı olan **çay**ı sonsuza kadar demleyen, abartılı, gereksiz ve tamamen ciddi bir simülatördür. 

Eğer çay demlenmezse, uzay-zaman sürekliliği bozulur. Bilimsel olarak kanıtlanmıştır (kaynak: benim hayal gücüm).

## Özellikler

- Sonsuz döngüde çay demler
- Dramatik Türkçe yorumlar yapar
- Rastgele şeker ekler, demlikle konuşur, çayın ruhunu çağırır
- Bazen çay soğur, bazen evreni kurtarır
- Gerçekten çalışır (Ctrl+C ile durdurabilirsiniz, eğer cesaretiniz varsa)

## Kullanım

```bash
python cay_demle.py
```

Sonra oturun, çayınızı için ve hayatın anlamını sorgulayın.

## Uyarı

Bu program sonsuz çalışır. Bilgisayarınız çay kokmaya başlarsa normaldir.

## Katkıda Bulunun

Pull request'lerinizi bekliyorum. Ama çay demlemeyi unutmayın.
